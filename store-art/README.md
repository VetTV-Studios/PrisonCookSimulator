# Store art (spec: docs/store-art-spec.md, Game Art Director v1)
Base illustrations in `source/` were generated by AI image generation, with no text in the images. The title was added afterward with `tools/gen_store_art.py`, set in Black Ops One (SIL OFL 1.1, license in `fonts/OFL.txt`).
Sources are about 1024 px, so the 2160 px masters are upscaled. Replace them with higher-res paintovers before final submission if possible.

## v2 (after Game Art Director audit)
- Masters now come from 4× Real-ESRGAN x4plus upscales (`source/x4/`, made with `tools/upscale_esrgan.py` on CPU). Every delivered size is a downscale of those masters, and the title is set at full resolution.
- The hero was regenerated using the key-art cook as a reference image, so it's the same character: clean-shaven, hairnet, apron, orange jumpsuit.
- The poster was regenerated with grey and charcoal inmates, so the cook is the only orange element. It's a fuller-body pose, though the counter covers his legs.
- The cover's title and the cook's head both sit inside the central 560×440 safe area.
